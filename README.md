# Pertemuan 4: Pernyataan Kondisional IF-ELSE

## Deskripsi
Proyek ini berisi implementasi struktur kontrol percabangan pada Python 3 yang dipelajari dalam Pertemuan 4. Materi mencakup pernyataan `if`, `if-else`, `elif` majemuk, serta percabangan bersarang (`nested if`).

## Program yang Tersedia
1. `01_if_sederhana.py`: Penggunaan perintah `if` sederhana dan evaluasi kondisi Boolean dasar.
2. `02_if_else_genap_ganjil.py`: Penggunaan klausa `else` untuk menentukan apakah suatu angka genap atau ganjil.
3. `03_elif_vokal.py`: Penggunaan struktur `elif` untuk memeriksa huruf vokal (`a`, `e`, `i`, `o`, `u`).
4. `04_if_bersarang_huruf.py`: Pernyataan `if` di dalam `if` untuk memeriksa jenis huruf (kapital/kecil) dan menentukan nilai terbesar dari 3 angka.

## Cara Menjalankan
Jalankan file yang diinginkan:
```bash
python 01_if_sederhana.py
python 02_if_else_genap_ganjil.py
python 03_elif_vokal.py
python 04_if_bersarang_huruf.py
```
